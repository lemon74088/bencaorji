本草观察日记
本草观察日记｜个人中医观察与药物反馈系统

本草观察日记是一款结合中医身体记录、中药服用追踪与历史经验分析的个人管理工具。

通过日期、二十四节气、身体症状、六部脉象、舌象及药物服用记录，持续累积个人观察资料，帮助使用者追踪身体变化，并整理每次用药后的反馈。

核心功能

1. 节气记录：记录日期、年月与二十四节气，建立长期观察时间轴。
2. 身体观察：以点选方式记录常见症状、寒热、汗出、睡眠、饮食、二便及精神状态，并支持自定义项目。
3. 六部脉象：采用左右两列、寸关尺直立排列，支持各部位独立多选、自定义脉象及补充描述。
4. 中药管理：记录科学中药、中药饮片、单味药材及复方，保存药物组成、剂量与服用时间。
5. 服药反馈：记录身体改善、无明显变化、症状加重及新出现的不适。
6. 历史对比：依日期、症状、脉象、药物及反馈查询过往记录，观察重复出现的现象。
7. 经验记忆：保留良好反应、无效记录与不良反应，在相似情况出现时提供历史资料参考。

设计理念

以简洁、清晰、易操作为原则，采用本草绿、米白及分类色彩，让日常记录更加轻松。常见项目以点选为主，特殊情况可自由输入，并支持自定义观察项目。

第一阶段以个人使用为主，优先采用浏览器本地储存，并提供资料备份与恢复功能，逐步建立个人本草观察数据库。

本草观察日记的目标，是让每一次身体观察与药物反馈都有迹可循，让长期累积的资料成为日后辨证思考与经验整理的参考。

系统提供的是资料整理与观察线索，不自动认定药物疗效或替代专业判断。
